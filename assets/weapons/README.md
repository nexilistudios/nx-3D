# Weapon models

`ak47.obj`, `m16.obj`, `glock.obj`, `usp.obj`, `deagle.obj`, and `mp5.obj` are
original low-poly models generated by `generate.py`. They point along +Z and
use +Y as up. Each MTL material uses a generated 1-pixel PNG swatch because
the Vulkan OBJ renderer reads diffuse textures.

Run `python3 assets/weapons/generate.py` from the repository root to rebuild
the OBJ, MTL, and PNG files. The models are used both in first person and as
dropped pickups. Team assignment, scale, and placement are in
`client/gamemode/weapon_profiles.hh`.

`knife.obj` and `grenade.obj` are small hand-authored utility models. Their
materials reuse the generated firearm swatches.
